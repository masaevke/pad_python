# Краткий лог использования AI-ассистента Codex

Исходный `pg2core_generator.py` существовал до этой доработки и использовался
для задач миграции ADWH (MSSQL) → ADB (Greenplum). Ниже приведены выборочные
вопросы из переписки и принятые решения.

| Конкретный вопрос автора | Что обсудили |
| --- | --- |
| «для тестового запуска создай файл с метаданными чтобы сымитировать запуск утиилиты» | Использование JSON с описаниями колонок и ключей вместо подключения к PostgreSQL; отдельный JSON с настройками генерации. |
| «реализуй собственное исключение» | Собственный класс `MetadataValidationError`, наследование от `ValueError` и обработку отсутствующей таблицы с кодом завершения `1`. |
| «в требованиях только если используются табличные данные - у меня в проекте их нет» | Условие применения pandas. Решили не добавлять pandas: утилита работает с описаниями схем, а не со строками бизнес-таблиц. |

## Участие в доработке

По отдельным запросам ассистент также вносил изменения в локальные файлы:
упаковку проекта, собственное исключение и его обработку, аннотации типов,
классы данных, pytest-тесты, демонстрационные JSON и README.

Решения и уточнения приходилось исправлять, чтобы сохранить контекст миграции ADWH → ADB,
использовать при типизации, отказаться от добавления pandas.
Изменения готовились отдельными этапами для последующего просмотра и коммитов.

При проверке ассистент получил `33 passed` в pytest и отсутствие ошибок
в строгом mypy для двух модулей; демонстрационный запуск проверялся без БД и API, так как данная утилита предназначена для запуска в закрытом контуре компании.
